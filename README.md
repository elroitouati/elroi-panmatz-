# אלרואי | פנמ"צ

אפליקציית מובייל אישית ללי ליווי ההכנה לקבלה לפנימייה הצבאית לפיקוד בחיפה (פנמ"צ),
לאורך כיתה ט': הרשמה → מבחן פסיכוטכני → יום שדה → בדיקות רפואיות → קורס הכנה בקיץ.

בנויה ב-**React Native + Expo**, עם שמירת נתונים **מקומית בלבד** על המכשיר (בלי שרת, בלי חשבון),
התראות פוש מקומיות, ערכת נושא כהה קבועה בהשראת המותג של פנמ"צ, וכיוון **RTL מלא**.

## הרצה מהירה

```bash
npm install
npx expo start
```

סרקו את קוד ה-QR עם אפליקציית **Expo Go** (iOS/Android) כדי להריץ על הנייד.

### בנייה להתקנה אמיתית (APK/IPA)

```bash
npm install -g eas-cli
eas build --platform android   # או ios
```

## מבנה

- `App.js` — נקודת כניסה, ניווט תחתון (4 טאבים) + מסך הגדרות, RTL, ערכת נושא.
- `src/context/AppContext.js` — כל מצב האפליקציה, שמירה מקומית וסנכרון התראות.
- `src/screens/` — מסכי הבית, כושר, הלוח, פסיכוטכני, הגדרות.
- `src/components/` — רכיבי UI (כרטיסים, מפת מסלול, כרטיס יעד, גרף, מודלים, חגיגה).
- `src/data/defaults.js` — שלבי המסלול, יעדי הכושר ההתחלתיים וקישורי הפסיכוטכני.
- `src/utils/` — עזרי תאריכים, לוגיקת שלבים ולוגיקת יעדים מתקדמים.

## נקודת פתיחה (כושר)

מוגדרת מראש לפי המצב האמיתי: 0–2 עליות מתח ברצף, ריצת 2 ק"מ מתחת ל-10 דק'.
דגש חזק על **מתח** (החולשה — התקדמות עדינה של חזרה בכל פעם) ועדינות ב**ריצה** (כבר חוזק).
כל יעד מתקדם בנפרד עם כפתור "קל לי", ובהגעה ליעד הסופי עובר אוטומטית ל**מצב תחזוקה**.

## הערות

- כל הנתונים מקומיים למכשיר. אין הרשמה/פרופיל/ריבוי משתמשים.
- תאריכי השלבים מוזנים ידנית במסך ההגדרות כשהם נודעים; עד אז מסך הבית מציג חודש משוער בלבד.
